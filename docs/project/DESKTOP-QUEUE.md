# 主控队列管理

KTVS-044 为主控提供活动队列刷新、拖放排序、上移、下移、插播（置顶）和删除。所有操作经过 `IRoomQueueService`，仅主持人身份可重排，且只能修改等待项；正在准备、播放或暂停的项目不会被移动或删除。

任意排序使用仓储事务执行两阶段位置重编号，先写入互不冲突的临时位置，再写入最终稀疏序号，从而避开 SQLite `(RoomSessionId, Position)` 唯一索引交换冲突；两个阶段位于同一事务，失败不会暴露中间顺序。删除沿用软跳过，不删除队列历史或媒体。

WPF code-behind 仅把拖放手势转换成 ViewModel 调用，不包含队列业务。无活动房间时页面保持安全空态，KTVS-046 建立房间后注入主持人上下文。
