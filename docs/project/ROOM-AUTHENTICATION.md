# 房间认证基线

KTVS-028 按 ADR-0006 实现房间限定的短期令牌。访客使用六位加入码和昵称加入；主持人令牌只能由受信任的本机管理入口签发，不能通过访客加入流程升级。

- 令牌由 32 字节密码学随机数生成，API 仅在签发时返回明文。
- SQLite 只保存 SHA-256 哈希；日志、DTO 和二维码不得写入完整令牌。
- 访客令牌有效 12 小时，主持人令牌有效 8 小时；关闭房间、到期或显式撤销后验证失败。
- 访客可浏览曲库/队列、点歌及删除自己的点歌；播放控制、全队列管理和房间管理仅限主持人。
- 后续 API 必须在每次变更时调用服务端授权策略，不能依赖客户端按钮可见性。

自动测试覆盖访客/主持人隔离、哈希持久化、过期、撤销、关闭房间、输入验证和权限矩阵。二维码与手机重连仍待局域网实机验收。

主控访客列表只投影昵称、角色、加入/到期时间和撤销状态。二维码只编码局域网 URL 和六位加入码，明确禁止令牌及哈希进入二维码。
