# 原唱/伴奏轨道映射

KTVS-024 使用媒体探测得到的音频轨标题生成角色候选。中文“伴奏/原唱/人声”和常见英文 `instrumental`、`karaoke`、`off vocal`、`lead vocal` 等标题形成高置信候选；无标题双轨只形成 25 分的顺序提示，不自动写成确定角色，避免错误切轨。

自动解析只选择置信度至少 80 且角色不冲突的轨道，并在扫描探测成功后写入 `TrackMapping`。用户人工修正使用同一实体并设置 `IsManualOverride`；扫描器显式加载该映射且绝不覆盖人工值。解析服务只要确认所引用音频轨仍存在，就始终优先使用人工值；轨道消失时安全回退到重新识别，不删除媒体或歌曲索引。

映射服务和分类器位于 Application，EF Core 仓储位于 Infrastructure。公开结果只含媒体内部 ID、流 ID、候选理由和置信度，不包含文件路径。生成夹具验证标题规则；真实曲库中的左右声道及标题语义仍待实机验收。
