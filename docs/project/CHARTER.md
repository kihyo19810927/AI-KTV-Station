# 产品章程：AI-KTV Station

## 目标

为 Windows 11 家庭聚会提供局域网 KTV：主机索引和播放挂载的成品 MKV，手机浏览器扫码入房、搜索和点歌。

## 产品边界

Station 负责媒体只读索引、搜索、房间、队列、播放控制、状态同步和诊断。AI-KTV-Builder 负责下载、分离、歌词、字幕和 MKV 制作；两者不合并、不共享内部领域代码。首版 Web 服务不代理视频，mpv 直接读取主机挂载路径。

明确禁止：公网开放、账号或云盘凭据处理、删除/移动/重命名真实媒体、手机获取 Windows 路径、因远端离线删除索引、把业务逻辑放入 WPF code-behind/API endpoint。

## 角色

- 主持人：管理房间、队列、播放、音轨/字幕、扫描和诊断。
- 访客：以昵称加入房间、搜索、点歌、查看队列、删除自己的等待项。
- 维护者：配置媒体源、播放器和端口，备份恢复数据库，查看日志。

## 核心用例

1. 维护者配置一个或多个只读媒体根目录并执行扫描；远端不可用时保留歌曲索引并标记离线。
2. 主持人创建房间并展示二维码；访客通过局域网浏览器以短期会话加入。
3. 访客搜索歌曲并点歌；服务按房间规则写入持久化队列并通过 SignalR 同步。
4. 播放编排器通过 `IPlayerAdapter` 播放队首，处理暂停、切歌、重唱、音量、音轨和字幕。
5. 播放完成或失败只推进一次；不可用媒体记录错误并自动尝试下一首。

## 领域词汇

| 术语 | 定义 |
|---|---|
| MediaSource | 用户配置的只读媒体根目录及其可用性状态 |
| Song | 曲库中可搜索的歌曲身份和人工元数据，不等同于当前文件是否在线 |
| MediaAsset | Song 关联的具体 MKV 文件及路径指纹、探测信息和可用性 |
| Track | 容器中的音频或字幕轨，具有类型、编号、语言和标签 |
| Room | 一次聚会的短期点歌空间及访客会话边界 |
| Host | 可执行管理和播放控制的主持人权限主体 |
| Guest | 只能执行访客允许操作的临时主体 |
| QueueItem | 某访客将某首歌加入房间队列的一次持久化请求 |
| PlayerAdapter | 播放器能力、状态和事件的稳定应用边界 |
| Offline | 媒体源或文件暂时不可访问；不代表删除 Song |
| Scan | 只读枚举、探测、更新索引和生成错误报告的过程 |

## 成功与非目标

V1 目标、性能和阶段门禁以权威开发计划为准。V1 不包含麦克风混音、评分、SaaS、多云迁移或自动媒体整理。真实电视、功放、手机、115 挂载和样本 MKV 的结果必须由用户验收后才能标为通过。
