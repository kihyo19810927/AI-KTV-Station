# Windows 设置与诊断

KTVS-047 在主控的“设置与诊断”页提供以下本机配置：监听地址、服务端口、数据目录、mpv 可执行文件和播放器命令超时。设置保存在当前 Windows 用户的 LocalAppData 中，不写入仓库；保存成功后提示重启生效，避免运行中部分服务使用新配置、部分服务仍使用旧配置。

“导出脱敏诊断报告”在 LocalAppData 的 `diagnostics` 目录生成 JSON。报告公开框架、系统架构、非敏感网络配置、路径是否已配置、健康摘要、恢复建议和最近受控事件；真实数据目录、媒体路径、mpv 路径、房间令牌、凭据及原始异常均不导出。

恢复操作遵守保留原则：数据库异常先备份，禁止删库重建；挂载异常恢复后只重扫选定来源，离线索引继续保留；播放器异常先检查配置或 WinGet 安装，再重启主控。设置页不会删除数据库或读写媒体文件。
