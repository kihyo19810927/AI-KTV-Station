# CloudDrive 故障注入

KTVS-050 使用临时 SQLite、临时媒体文件和可控端口模拟以下故障，不访问真实 115 或 CloudDrive 挂载：

- 挂载不可枚举：扫描记录稳定错误，媒体源变为 `Unknown`；已有歌曲和媒体仍为可用，不因本次未看到文件而删除或标离线。
- 挂载恢复：下一次只读扫描重新确认同一媒体记录，不创建重复歌曲。
- HTTP 403 类媒体不可用：播放恢复服务记录 `player.media_http_403`，媒体暂时标为 `Offline`，歌曲、媒体 ID、错误历史和人工音轨映射全部保留。
- 403 后恢复：文件重新可见时只读增量扫描把同一媒体恢复为 `Available` 并清除临时错误，不删除数据库。
- 播放命令超时：有限恢复策略重启播放器、替换播放实例 ID、重载同一队列项；成功完成后队列与历史进入完成态。

这些自动测试验证故障分类和数据保留规则，不证明真实 CloudDrive 会返回完全相同的底层错误文本。真实断挂、403、恢复时延和网络抖动需在用户选定的小批曲库上验收，且不应先扫描整个曲库。
