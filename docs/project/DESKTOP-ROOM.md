# 主控房间与二维码

KTVS-046 将房间创建/恢复/关闭、访客列表与撤销、每位访客排队上限接入 WPF。桌面启动后从 SQLite 恢复唯一开放房间；若本机主持人上下文不存在或到期，使用受信任本机入口签发新的短期主持人身份。

二维码由 QRCoder 1.8.0 生成 PNG，只包含 `http://<局域网 IPv4>:<端口>/?room=<六位加入码>`。二维码不包含主持人令牌、访客令牌、Windows 路径、云盘凭据或永久管理员密钥。QRCoder NuGet 包声明 MIT 许可证，正式依赖清单将在 KTVS-053 统一复核。

WPF 可开启/关闭房间、调整 1–100 首访客排队上限、查看主持人/访客公开状态并撤销访客。公开访客 DTO 不包含令牌或哈希。内嵌 Web 服务生命周期在 KTVS-048 接通前，二维码 URL 仅代表计划监听地址；手机扫码连通性、多个网卡地址选择和路由器隔离需实机验收。
