# Web 曲库搜索

KTVS-036 将确认 Demo 的发现页接入认证接口 `GET /api/catalog/search`。

## 行为

- 页面进入时加载第一页；输入歌名、歌手、简繁体、全拼或简拼后等待 300ms 再请求。
- 新输入或筛选会取消上一请求并回到第一页，避免旧响应覆盖新结果。
- 支持语言、分类、画质和相关度/歌名/年份排序。
- 每页 20 首，通过“继续加载”追加下一页并显示当前数量和总数。
- 明确显示首次加载、无结果、API 错误和重试状态；离线或不可读歌曲不可点播。
- 请求只携带公开筛选值和短期 Bearer 令牌，不返回或展示 Windows 媒体路径。

筛选选项首版采用家庭 KTV 常见值；后续若曲库出现其他值，可由聚合字典接口替代固定选项，不改变搜索契约。

## 自动验证

Vitest 覆盖输入防抖后的查询参数、筛选、结果渲染、错误重试、空状态和分页追加。真实大曲库滚动体验与手机软键盘由 KTVS-040 实机验收。
