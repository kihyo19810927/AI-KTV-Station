# 用户验收测试包

本验收包用于 AI-KTV Station V1 候选版。自动化就绪检查不代替真实电视、功放、手机或 115/CloudDrive 挂载验收，也不会扫描、移动或修改真实媒体。

## 1. 软件就绪检查

在仓库根目录用 PowerShell 7 执行：

```powershell
pwsh.exe -ExecutionPolicy Bypass -File scripts/run-uat-readiness.ps1
```

成功标志为 `BUILD=passed`、全部测试通过、`ENVIRONMENT_BASELINE=passed` 和 `UAT_READINESS=passed`。脚本只生成可重复创建的 Unicode 测试夹具，不接触真实曲库。

## 2. 主控与样例房间

1. 启动 `src/Station.Desktop`，确认仪表盘显示数据库、播放器与点歌服务状态。
2. 在“房间”创建样例房间，确认二维码只含局域网地址和六位房间码。
3. 用同一局域网的一台 Android 或 iPhone 扫码，加入房间并刷新页面。
4. 在手机搜索歌曲、点歌、取消自己的等待歌曲；在主控执行置顶、重排和删除。
5. 确认新点歌曲目无需重启主控即可自动开始，并在结束后自动播放下一首。

记录：日期、Windows 版本、手机型号/浏览器、连接方式、通过/失败、可复现步骤。不得记录房间令牌或本机真实路径。

## 3. 小批真实 115 曲库验收

只选择用户明确指定的小目录，建议 5–20 首，不得选择挂载根目录或全库。添加目录不会自动扫描；再次核对所选目录后再手动开始扫描。

- MKV、MPG/MPEG 视频应入库；KSC 只作为歌词关联；RAR 应忽略。
- 无 NFO 的歌曲应通过文件名建立索引；NFO 异常不得阻断其他文件。
- 原唱/伴奏标题和字幕应可识别；不确定的双音轨不得武断覆盖人工映射。
- 暂时断挂或 403 只标记离线并记录错误，不删除歌曲、收藏、历史或人工修正。
- 恢复挂载后执行增量重扫，应复用原记录并恢复可用状态。
- 按年度或目录逐批追加；小批验收通过前不得全库扫描。

禁止通过删除 `station.db` 转正式库。正式数据升级必须先备份并执行迁移，确认收藏、播放历史和人工音轨修正仍存在。

## 4. 播放与设备验收

- 连续播放至少 50 首真实歌曲，核对自动下一首、跳过和故障恢复。
- 在电视上核对画面比例、全屏、中文字幕与长时间运行。
- 在功放上核对音量和原唱/伴奏切换语义，不以音轨标题单独判定真实声道。
- 播放期间模拟一次 CloudDrive 暂时不可用，确认系统保留队列/索引并在恢复后可继续。
- 突然关闭并重启主控，确认活动队列回到等待、未闭合历史被安全终结。

## 5. 诊断与失败记录

发生失败时从“诊断”导出脱敏报告，并附操作步骤、时间和公开错误码。提交前确认报告不含 Windows 路径、云盘凭据、令牌、Cookie 或个人数据。真实设备结果统一记录为 `通过`、`失败` 或 `待实机验收`；不得用自动化或模拟结果替代。
