# 房间实时协议

KTVS-032 使用 `/hubs/room` SignalR Hub。连接建立后，客户端调用 `Subscribe(token, afterVersion)`；短期令牌作为 Hub 调用参数发送，不放入 URL 查询字符串，避免服务器访问日志记录令牌。

- 首次连接或事件版本已超出保留窗口时，返回包含当前队列、播放进度和版本号的完整快照。
- 重连且版本连续时，仅返回 `afterVersion` 之后的增量事件。
- 每个房间维护单调递增版本，内存中最多保留 256 个事件；V1 单进程重启后客户端自动回退到完整快照。
- REST 房间、成员、队列和播放变更发布到房间 SignalR 组；事件载荷不包含媒体路径、令牌或令牌哈希。
- 未验证、过期、撤销或已关闭房间的令牌不能加入房间组。

自动集成测试通过真实 SignalR Long Polling 覆盖在线事件、断线期间事件补发、保留窗口缺口回退和无效令牌拒绝。WebSocket、手机锁屏重连和局域网网络切换待实机验收。
