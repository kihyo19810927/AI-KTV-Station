# 主控播放控制台

KTVS-043 按已确认 Demo 的紫色卡片布局实现 WPF 播放控制台，提供状态刷新、播放、暂停、进度定位、音量、原唱/伴奏音轨和字幕开关。

`PlaybackConsoleViewModel` 只调用 Application 层 `PlaybackControlService`；新增的完整快照查询同样通过该服务转发，WPF 不引用 mpv IPC、管道、命令或媒体路径。失败只显示稳定的公开错误信息。播放器进程和当前歌曲由既有编排器负责，控制台不会自行绕过队列加载媒体。

自动测试覆盖状态投影、轨道类型分组和音量命令链。真实 MKV 的语义标签、电视画面、功放音量和遥控体验待实机验收。
