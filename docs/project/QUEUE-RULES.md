# 点歌队列规则

KTVS-029 的队列服务以房间身份作为全部操作入口，公开队列项只包含歌曲、点歌人、位置和状态，不包含媒体路径。

- 新点歌曲目追加到等待队列；只有存在可用媒体的歌曲可加入。
- 访客的活动点歌数受房间 `MaxQueuedSongsPerGuest` 限制；主持人不受该访客额度限制。
- 访客只能删除自己的等待项，主持人可删除任意等待项；准备中、播放中及终态项目不可通过队列编辑入口修改。
- 只有主持人可置顶等待项。位置采用带间隔的唯一整数键，读取始终按位置升序，确保稳定排序。
- 同一房间写操作由进程内房间锁串行化；V1 为单服务进程。将来若支持多服务实例，必须升级为数据库租约或分布式锁。
- 删除采用状态转换为 `Skipped` 并记录完成时间，保留历史事实，不物理删除记录。

测试覆盖追加顺序、访客额度、本人/主持人删除、置顶权限、20 路并发点歌和不可用媒体拒绝。
