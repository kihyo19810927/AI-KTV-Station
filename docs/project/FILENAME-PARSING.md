# KTV 文件名解析

解析器从右向左移除已知语言和类别标签，再识别方括号清晰度及尾部版本标签，最后只用剩余核心的第一个连接符分隔歌手与标题，因此标题内部连接符会保留。支持半角/全角连接符、括号和 Unicode NFKC 规范化。

下划线生成多歌手候选，同时保留歌手显示串。结果包含 `Confidence` 与稳定 warning code；无法识别歌手时用完整文件名（不含扩展名）回退，仍允许入库。人工修正优先级将在元数据更新用例中落实，NFO 由 KTVS-016 独立处理。

回归样本包含开发计划的三种格式、全角符号、标题内连字符、多歌手及不可解析回退。真实曲库样本需脱敏后追加，不能提交私人文件名清单。
