# 主控曲库管理

KTVS-045 按确认 Demo 实现主控曲库搜索、歌曲详情、人工元数据修正、媒体源添加和单目录扫描。管理员可把已完成的年度或月份目录分别登记为媒体源，扫描完成立即重建派生 FTS 索引；后续目录继续追加到同一个 SQLite 数据库，无需等待全部年份迁移。

## 格式与辅助文件策略

- 可播放媒体：`.mkv`、`.mpg`、`.mpeg`、`.mp4`、`.avi`、`.vob`、`.ts`、`.m2ts`、`.wmv`、`.mov`，均继续由 ffprobe 探测、mpv 播放。
- `.ksc`：按同目录同文件名主干关联到媒体的歌词伴随元数据，记录格式和相对路径；它不是视频，不单独生成 Song，也不直接加入队列。KSC 文本解析/渲染能力需另行验证，不能冒充已支持字幕显示。
- `.rar`：明确分类为忽略的归档，不解压、不探测、不建 Song、不进入队列。
- 其他扩展名：忽略，不当作媒体。
- NFO：完全可选；缺失时使用文件名解析结果正常建库。

## 数据安全与迁移

桌面程序启动只执行 EF Core 增量迁移。KSC 元数据通过新增 nullable 列加入现有 `MediaFiles`，不删除或重建数据库。自动升级测试从上一迁移版本预置歌曲、收藏、播放历史和人工音轨映射，升级后逐项确认仍存在。

正式库验收顺序：先选择一个小型年度/月度目录进行只读扫描，核对 MPG、KSC、RAR、无 NFO、音轨与搜索结果；通过后再按目录逐批扩大，最后才进行全库扫描。真实挂载仅供只读参阅，自动测试不依赖它。
