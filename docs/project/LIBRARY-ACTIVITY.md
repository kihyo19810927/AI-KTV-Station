# 收藏、历史与热门统计

KTVS-033 将用户活动保持为数据库事实，不依赖前端本地缓存：

- 收藏以 `(GuestId, SongId)` 为唯一键，添加/取消均幂等并严格限定到当前访客。
- 播放历史按房间隔离，按开始时间倒序分页，保留播放结果与结束时间。
- 热门榜仅统计成功完成的播放，按播放次数、最近播放时间和歌曲 ID 稳定排序。
- SQLite 的 `DateTimeOffset` 排序限制通过参数化 SQL 排序/聚合解决，不把整库历史加载到内存。
- 所有公开 DTO 和 API 不包含媒体路径；收藏变化通过 SignalR 发布，但不泄露令牌。

自动测试覆盖幂等收藏、访客隔离、历史分页/房间隔离、热门聚合、无效身份，以及 REST 端到端查询。
