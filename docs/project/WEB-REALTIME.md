# Web 房间实时同步

KTVS-038 使用既有 `/hubs/room` SignalR Hub，让确认 Demo 的连接状态、正在播放卡片和“我的点歌”消费同一份版本化房间状态。

## 连接与认证

- Hub URL 固定为 `/hubs/room`，短期令牌不放入 URL、查询参数或日志。
- 连接建立后调用 `Subscribe(token, afterVersion)`；首次传 `null`，重连携带客户端最后接受的版本。
- 自动重连间隔为立即、1 秒、3 秒、10 秒，界面显示连接中、已连接、重连中或离线。
- 组件卸载或退出房间时停止连接并注销事件处理。

## 一致性

- 完整快照原子替换队列和播放进度。
- 增量事件只在版本严格递增时应用，重复或迟到事件被忽略。
- 支持 `queue.added`、`queue.removed`、`queue.reordered` 和 `playback.changed`；其他事件推进版本但不猜测业务状态。
- 服务端无法补齐版本缺口时会返回完整快照，客户端使用同一同步入口恢复。

正在播放标题从状态为 `Playing`/`Preparing` 的公开队列项解析；播放进度中不包含媒体路径。当前进度仅随服务端事件/快照更新，连续秒级进度动画可在主控播放体验任务中补充。

## 验证边界

Vitest 覆盖版本幂等、增加/删除/重排、播放状态、快照渲染及令牌不进入 Hub URL。服务端真实 SignalR 客户端测试已覆盖在线推送和断线增量恢复；手机 WebSocket、Wi-Fi 切换和休眠恢复待实机验收。
