# Web 房间会话

## 范围

手机端通过 `POST /api/rooms/join` 使用房间码和昵称加入房间。成功响应中的短期令牌只保存在当前浏览器标签页的 `sessionStorage`，刷新页面可以恢复；关闭标签页、令牌到期或用户退出后不再恢复。

## 安全约束

- 不使用 `localStorage`、Cookie 或 URL 参数持久化令牌。
- URL 查询参数只允许预填房间码，不携带令牌。
- 客户端只保存公开房间标识、显示名称、昵称、角色、令牌及到期时间。
- 解析失败、字段缺失或已到期的记录立即从 `sessionStorage` 清除。
- 服务端仍是授权权威；本地角色只用于界面展示，不能代替 API 权限检查。

## 用户流程

1. 扫码或打开 `/join?code=房间码`。
2. 输入昵称并加入房间。
3. 加入成功后进入 `/room/discover`，刷新可恢复当前会话。
4. 从加入页可继续尚未到期的房间；点击“退出”会清除本标签页会话。

## 验证边界

自动测试覆盖加入请求、预填房间码、刷新恢复、退出清除、过期和损坏记录清理。二维码、iPhone/Android 浏览器标签页生命周期与局域网断线恢复仍待实机验收。
