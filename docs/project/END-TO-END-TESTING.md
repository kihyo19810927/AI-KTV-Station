# 端到端自动化

KTVS-048 使用独立临时目录和 SQLite 数据库验证首要业务链路：创建 Unicode 曲库夹具及 MPG/KSC 文件，经真实文件枚举、扫描协调器和 FTS 索引后，通过 Minimal API 创建房间、加入访客、搜索歌曲并点歌，再由真实队列持久化与播放编排器加载媒体，最后注入播放器完成事件并核对队列和播放历史终态。

测试只替换两个外部边界：媒体探测器返回确定性轨道信息，`IPlayerAdapter` 记录加载请求并产生可控状态。文件枚举、元数据解析、SQLite、FTS、认证、REST、队列规则、媒体路径选择、播放编排和历史持久化均使用正式实现。夹具位于测试临时目录，测试结束后删除；不会访问或修改真实曲库。

自动化证明软件模块之间的契约可以闭环，但不等同于真实设备验收。真实 ffprobe/mpv 已由各自外部测试覆盖；115 小批歌曲、电视、功放、手机扫码和 Wi-Fi 连通仍保持待实机验收。
