# AI-KTV Station 1.0.0 发布说明（待发布）

状态：发布材料已准备，尚未创建 `v1.0.0` Tag 或 GitHub Release。正式发布必须先完成 `CANDIDATE-VALIDATION.md` 的实机项目、确定项目许可，并取得仓库所有者授权。

## 主要功能

- Windows 11 WPF 主控提供健康状态、播放控制、队列、曲库、房间和诊断页面。
- 手机浏览器通过局域网加入房间，支持搜索、点歌、队列实时同步、切歌、音量、原唱/伴奏和字幕控制，并按歌星、语种与风格筛选。
- SQLite 保留歌曲索引、人工元数据、人工音轨映射、收藏和播放历史；升级前自动备份，失败恢复。
- 只读增量扫描 MKV、MPG/MPEG、MP4、AVI、VOB、TS/M2TS、WMV 和 MOV；KSC 仅关联歌词，RAR 忽略；无 NFO 也可按文件名建库。
- mpv JSON IPC 支持播放、暂停、定位、音量、字幕、原唱/伴奏切换、自动下一首和有限故障恢复。

## 安装与升级

使用 win-x64 自包含 ZIP，按包内 `INSTALL.md` 安装。mpv 与 FFmpeg/ffprobe 必须由用户从可信来源单独安装，发布包不捆绑媒体工具。

升级前备份程序目录和 `%LOCALAPPDATA%\AI-KTV Station`。不得删除或替换既有 `station.db` 来“重新建库”；应用会对待迁移数据库创建一致性备份并在失败时恢复。
