# 播放控制边界

KTVS-023 的 `PlaybackControlService` 是 UI/API 与 `IPlayerAdapter` 之间的 Application 服务。它集中处理音量、进度、定位和字幕选择的业务校验，调用方无需了解 mpv 属性或 JSON IPC。

- 音量范围为 0～100，非法值不调用适配器。
- 进度 DTO 只包含播放实例、状态、当前位置和时长，不包含媒体路径或轨道明细。
- 定位和字幕控制要求当前处于 Playing/Paused 且存在 `PlaybackId`；已知时长时禁止定位到媒体末尾之后。
- 字幕 ID 必须匹配当前快照中的字幕轨；`null` 表示关闭字幕。
- 成功结果来自适配器命令后的状态回读，适配器稳定错误码原样向上返回。

真实电视字幕渲染、遥控操作感受和功放音量曲线仍为待实机验收。
