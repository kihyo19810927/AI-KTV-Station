# 只读增量扫描

扫描流程只读取启用的 `MediaSource`，递归枚举受支持视频（MKV、MPG/MPEG、MP4、AVI、VOB、TS/M2TS、WMV、MOV）、KSC 歌词伴随文件和 RAR 归档（大小写不敏感）。只有视频建立 `MediaFile`；同主干 KSC 关联到视频，RAR 明确忽略且绝不解压或入队。相对路径规范化为 `/`，以 `MediaSourceId + RelativePath` 作为视频身份。大小、修改时间或离线状态发生变化时更新记录；未变化文件不写入更新计数。

每 100 个枚举项保存一次检查点。取消会保存 `Cancelled` 状态和最后相对路径；目录或文件访问错误转换为条目级错误并继续。只有一次扫描完全没有枚举错误时，未见到的已有媒体才标为 `Offline`，记录仍保留；出现局部错误时不推断未见文件离线。

新文件由文件名创建 Song 元数据；NFO 缺失是正常路径，不阻止入库。每个年度或月份可作为独立媒体源先行扫描并立即进入同一索引，后续继续追加。扫描器不写入、解压、重命名、移动或删除媒体。
