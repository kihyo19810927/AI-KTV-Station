# 只读增量扫描

扫描流程只读取启用的 `MediaSource`，递归枚举 `.mkv`（大小写不敏感），将相对路径规范化为 `/`，以 `MediaSourceId + RelativePath` 作为文件身份。大小、修改时间或离线状态发生变化时更新记录；未变化文件不写入更新计数。

每 100 个枚举项保存一次检查点。取消会保存 `Cancelled` 状态和最后相对路径；目录或文件访问错误转换为条目级错误并继续。只有一次扫描完全没有枚举错误时，未见到的已有媒体才标为 `Offline`，记录仍保留；出现局部错误时不推断未见文件离线。

新文件暂以文件名创建 Song 占位元数据；KTVS-014 负责正式文件名解析。扫描器不写入、重命名、移动或删除媒体。
