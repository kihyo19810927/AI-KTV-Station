# Web 点歌与我的歌曲

KTVS-037 将 Demo 的“＋”和“已点”页面接入认证队列 API。

## 点歌

- 点歌前刷新活动队列；同一访客已点过同一歌曲时提示重复，不重复提交。
- `POST /api/queue` 成功后给出明确确认；提交期间禁用当前歌曲按钮。
- 服务端继续权威执行房间状态、媒体可用性和每位访客上限。`queue.guest_limit_reached` 在手机端显示为可理解的额度提示。
- 离线或不可读歌曲在搜索结果中不可点播。

## 我的歌曲

- `GET /api/queue` 取得完整活动队列，但页面只展示 `requestedByGuestId` 等于当前短期会话访客的条目。
- 顶部显示“我已点”和房间总数，条目序号沿用房间队列顺序。
- 只有 `Waiting` 条目显示删除按钮；`DELETE /api/queue/{itemId}` 成功后立即从本地列表移除。
- 别人的条目不会出现在“我的点歌”，后端仍会再次检查删除权限。

客户端会话增加公开 `guestId` 用于归属判断；令牌存储和路径隔离规则不变。
