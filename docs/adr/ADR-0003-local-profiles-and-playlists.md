# ADR-0003：本地家庭账户与歌单

- 状态：Accepted
- 日期：2026-09-13
- 对应：KTVS-081

## 背景

房间 `Guest` 是短时、可撤销的扫码会话，不适合承载家庭成员长期收藏、常唱统计或自定义歌单。原有 `Favorites` 以 `GuestId` 作为主键，房间关闭或手机重新加入后无法自然复用。

## 决定

新增只在本机 SQLite 保存的 `UserProfile`、`ProfileDevice`、`ProfilePlaylist` 与 `ProfilePlaylistItem`。它们与房间 `Guest` 分离：房间令牌仍然只用于当前房间的点歌和播放权限；设备记忆令牌只证明成员对其个人歌单的访问权，不能获得主持人权限。

- 家庭账户默认无 PIN；PIN 是成员自行启用的可选保护项。
- “我的收藏”和“我常唱的”是系统歌单；后者按已完成播放历史聚合，均不可删除。
- 自定义歌单可选择家庭共享；媒体离线时只显示离线状态，不删除歌单条目。
- 旧 `Favorites` 表和内容保留，作为可认领的历史访客收藏；本次迁移不删除、重写或降级既有数据。
- 设备令牌仅在手机本地保存，并以哈希形式写入数据库；它不替代房间令牌，也不携带管理权限。

## 后果

长期偏好不再随临时访客会话失效，并可在家庭设备间按成员切换。新增迁移是追加式的；升级前现有数据库备份策略继续生效。真实家庭成员的头像、PIN 设置流程和历史认领交互需在实机验收中确认。
