# ADR-0015：本机 Server 管理接口与轻量托盘启动器

- 状态：Accepted
- 日期：2026-09-13
- 任务：KTVS-089

## 背景

桌面界面将逐步从 WPF 迁移为 Server 托管的 Web 桌面页。曲库 JSON/JSONL 导入、设置和诊断原先只由 WPF 直接调用，迁移期间会造成两套运行时配置和不必要的 UI 耦合。

## 决定

1. `Station.Server` 注册曲库导入、设置存储、健康检查、日志和脱敏诊断服务，并提供 `/api/manage/*` 管理端点。
2. 所有管理端点只接受 loopback 请求；它们不属于手机/局域网访客 API，不返回诊断文件的绝对路径。
3. 新增 `Station.Tray` WinForms 通知区启动器。它启动/停止同一 `Station.Server` Host，在启动后用 Edge `--app` 打开 `/desk`。
4. 退出时托盘启动器只调用已注册 `IPlayerAdapter` 的停止和 Host 的正常停止/释放。禁止按 `mpv.exe` 映像名批量结束进程，以免误伤用户的其他播放器。

## 后果

- `/desk` 视觉实现留给下一阶段；在此之前托盘已能验证 Server 生命周期和浏览器拉起链路。
- 设置保存明确返回“需要重启”，避免运行中部分重配产生不一致。
- JSON 导入仍读取主机本地文件，但该路径只在 loopback 管理请求中使用，不会暴露给手机。
