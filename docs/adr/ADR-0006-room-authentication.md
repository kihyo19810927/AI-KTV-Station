# ADR-0006：房间认证与局域网暴露

状态：Accepted  
日期：2026-09-03

## 决策

- V1 服务仅绑定用户明确配置的局域网接口；默认不开放公网、不自动修改防火墙或路由器。
- 二维码包含局域网地址、短期房间标识/加入信息，不包含管理员密钥或主机路径。
- 访客加入后获得短期、可撤销、限定房间与角色的会话令牌；主持人权限不复用访客令牌。
- 所有队列变更在服务端重新授权；客户端隐藏按钮不构成权限控制。
- 日志仅记录令牌指纹或会话 ID，不记录完整令牌、Cookie、路径或凭据。
- KTVS-028 采用 32 字节随机 Bearer 令牌并仅持久化 SHA-256 哈希；访客/主持人默认有效期分别为 12/8 小时，关闭房间视为令牌失效。
- KTVS-052 强制监听配置为显式 IP 地址，并把该地址/端口实际传给 Kestrel；扫描、开房和当前房间管理只接受 loopback 来源，且不启用可伪造来源地址的转发头。
- V1 局域网传输仍为 HTTP，依赖受信任家庭网络和短期令牌降低风险；不得将端口映射到公网。未来如支持不受信任网络，必须先新增 HTTPS/配对机制 ADR。

## 后果

家庭局域网使用保持轻量，同时限制二维码泄漏影响。令牌签发、撤销、过期、重连和权限矩阵需在 KTVS-028/031/032 自动测试。
