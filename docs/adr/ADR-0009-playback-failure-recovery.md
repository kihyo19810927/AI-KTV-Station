# ADR-0009：播放故障恢复边界

状态：Accepted
日期：2026-09-08

## 决策

- `IPlayerAdapter` 只分类并报告单次技术故障，不在内部执行无限重试或推进队列。
- Application 的恢复策略根据稳定 `PlayerFailureKind`、是否可重试和已完成重试次数，给出重试当前歌曲、跳过当前歌曲或停止播放编排的决定。
- 单曲最多自动重试两次，采用有上限的指数退避；进程/连接/协议类故障在重试前要求重启播放器。
- 每次故障都写入 `PlaybackError`。媒体不可用只更新 `MediaFile.Availability` 和错误码，不删除 Song、MediaFile 或队列数据。
- 可执行文件缺失、启动失败、非法状态/参数等系统性配置故障停止编排；不支持的单个媒体允许跳过，避免整晚队列被一首歌阻塞。

## 依据与后果

重试属于业务策略，放入 mpv 适配器会隐藏尝试次数并难以保证队列只推进一次。将“决定”和“执行”分离后，后续队列编排器可以按决定执行且保持可测试性。真实 CloudDrive 断挂、403 和电视链路恢复仍需实机验收；自动测试使用合成故障验证所有分支。
